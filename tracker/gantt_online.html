User Guide & Feature Manual - Online Edition

Welcome to the Project Tracker. This intuitive, single-page application is designed to simplify project scheduling, Gantt chart visualization, and automated progress reporting. Below is a quick, efficient guide to help you master every feature in the app.

Profiles, GitHub & Offline Recovery

  • Profiles: Use the top dropdown to switch separate projects, tasks, To Dos and reminder settings. New Profile creates an empty workspace. Profiles are not logins and do not provide separate permissions.
  • GitHub: Connect a dedicated private data repository with a fine-grained token limited to Contents: read/write. Files and the profile index are created automatically. The token is never stored; repository details are remembered.
  • Continuous sync: Edits save locally immediately and upload about two seconds after you stop editing. Cloud changes are checked on returning to the tab and every 30 seconds while visible. Wait for Synced before switching devices or closing the tab.
  • Offline: Once the page says Offline ready, the app can reopen offline. Cached profiles and pending changes remain available. On reconnect, unchanged cloud files receive local edits automatically; divergent versions produce a recovery dialog instead of an overwrite.
  • Recovery: Keep both places local edits in a separate recovered profile and retains the GitHub version in the original. Other choices retain a recovery snapshot. Recovery snapshots are local and included in Backup all profiles.
  • Local file: Each profile can link its own JSON file in Chrome or Edge. Links must be re-enabled after reopening. This is an additional backup, not a replacement for automatic GitHub sync.
  • Backups: Export Backup exports the current profile; Backup all profiles includes every profile and recovery snapshot. Import accepts old Tracker_Backup.json files and new profile backups. All-profile imports create new profiles without replacing existing ones.
  • Privacy: Public hosting contains only code. Local browser copies are not encrypted or protected by a login; use a trusted browser/device. Only one tracker tab can edit the shared browser cache at a time.

1. Project Workspace Management

Creating, Renaming & Deleting Projects

  • Create: Click the + button next to "Project Tracker" in the sidebar header to initialize a new project.
  • Rename: Hover over the project name in the sidebar and click the pencil icon, or click the project's title in the main header.
  • Delete: Hover over the project row in the sidebar and click the trash icon to permanently delete it.

Dynamic Views

Toggle between views in the top-right corner of the header toolbar:

  • Gantt View: Standard interactive timeline layout with editable columns.
  • Summary View: Clean, formatted textual breakdown of all tasks with progress markers—ideal for progress presentations.
  • Overview (Dashboard): Click "Overview" in the sidebar to view a high-level dashboard of all active projects, overall completion rates, and active timelines.

2. Managing Tasks and Hierarchy

Building a Task Tree

Tasks can be indented to create a parent-child relationship.

  • Add Subtasks: Hover over a task and click the green + icon to add a nested subtask.
  • Indent / Outdent: Click the < or > buttons in the task's hover menu to adjust hierarchy levels.
  • Automatic Parent Tracking: Parent tasks automatically adjust their start date, duration, and completion progress based on their children. You do not need to change them manually!

Progress Tracking

  • Click on any task's percentage value (e.g., 0%) to set manual progress.
  • Tip: Clear the percentage input box to revert the task (or parent) to automatic calculation mode.

Modifying and Duplicating

  • Duplicate Branch: Click the duplicate icon (overlapping squares) to copy a task and all of its subtasks instantly.
  • Rich Text Details: Double-click any task bar, or click the details folder icon to open the description editor. You can format notes, create bullet lists, and safely paste external documentation.

3. Interactive Gantt Timeline

Timeline Navigation

Use the Zoom View dropdown in the header to scale your timeline between Day, Week, or Month views.

Drag-and-Drop Scheduling

  • Move / Reschedule: Click and hold any task bar or milestone diamond, then drag it horizontally. If you drag a parent task, all of its nested children will shift in unison.
  • Resize Duration: Hover over the right edge of any non-parent task bar until your cursor changes to a horizontal resize arrow, then drag to extend or shorten the duration.
  • Milestones: To create a milestone, append an asterisk (*) to a task's name (e.g., Launch Phase*). This converts the bar into a purple milestone diamond with a duration of 0 days.

4. Saving and State Persistence

Your data is secured through three layered saving mechanisms:

A. Browser LocalStorage (Automatic)

The application automatically saves every action locally in your browser. If you refresh or close the page, your workspace will restore exactly where you left it.

B. Live Auto-Save (Linked Local File)

For secure, continuous backup directly onto your computer's hard drive:

  1. Click "Local file" in the main header.
  2. Your browser will prompt you to create or link a file (e.g., My_Tracker_Live.json).
  3. Once enabled, the button turns green. Every change you make in the app is silently synchronized to that file in real-time.

C. Manual Backups (Import / Export)

  • Export Backup: Click "Export Backup" to download your complete workspace data as a standalone JSON file.
  • Import Backup: Click "Import Backup" to upload a previously saved JSON file to restore your workspace on any device.

5. Exporting Assets

Generate instant stakeholder reports from the top-right header toolbar:

  • Export PNG Image: Generates a high-resolution, cropped visual snapshot of your Gantt timeline.
  • Export PDF Report: Generates a professional print-ready document containing your project overview, rich-text notes, structured task hierarchy tables, and the visual Gantt timeline.

6. To Do List

Click To Do in the sidebar to open a simple day-by-day checklist. It is completely separate from your Gantt schedules and never affects your project tasks.

Adding & Completing Items

  • Add: Type in the box at the bottom and press Enter. The cursor stays put so you can add several items in a row.
  • Complete: Tick the checkbox. The item is struck through but stays where it is in the list.
  • Edit: Click an item's text to open an Edit Item dialog—the same style as Edit Details in the Gantt view—where you can change the wording, the time and the project tag together. Press Enter to save, Shift+Enter for a new line, or Esc / click outside to cancel. Hover and click the trash icon to delete it.
  • Reorder: Drag an item by the ⋮⋮ grip on its left and drop it on another item to change the order.

Times & Reminders

  • Every item has a time box. When empty it takes no space at all—hover the row and the full control strip appears, with the text re-wrapping around it. You can set or clear the time at any point, not just when creating the item.
  • Setting a time turns the item into a reminder. Clearing the box removes the reminder. Once a timed item is past due its time badge turns red.
  • The To Do sidebar entry shows a live badge counting outstanding items (red if anything is overdue), and the browser tab title shows the same count.
  • When a reminder comes due you get a popup that stays on screen until you deal with it, with three buttons: Snooze 10m, Done, and Dismiss. Changing an item's time re-arms it and cancels any snooze.
  • If several reminders are due at once—for example after the laptop wakes from sleep—they are collected into a single grouped catch-up popup instead of stacking up.
  • While a reminder is waiting, the browser tab title flashes so you notice it even from another tab.
  • A short chime plays with each reminder. Use the speaker icon in the To Do header to mute or unmute it; the choice is remembered.
  • If your browser has already been granted notification permission for this page, reminders also fire as desktop notifications. Otherwise you simply get the on-screen popup. Permission is asked for at most once, ever—if you decline or ignore it, you will never be prompted again.
  • Daily wrap-up: the Wrap-up time box in the header (default 6:00 PM) gives you one reminder listing everything still open—today's unfinished items plus anything overdue—regardless of whether those items have their own time. It fires once a day; if the page was closed at that hour you get it the next time you open the file. Clear the box to switch it off.
  • Note: Because this is a standalone HTML file, reminders can only fire while the page is open in a tab. For anything you must not miss, export it to your calendar (below).

Sending Reminders to Outlook / Google Calendar

  • Hover a timed item and click the calendar-export icon to download a .ics file for it. Open the file and your calendar app will offer to add the event.
  • Use Export .ics next to the day's title to download every timed item for that day in one file.
  • Events are created at the item's time with a 30 minute duration and a 10 minute advance alarm. Untimed items become all-day events with no alarm.
  • Re-exporting the same item updates the existing calendar entry rather than creating a duplicate.
  • Important: this is a one-way copy, not a live sync. Editing or deleting the item here does not change an event you already added to your calendar—re-export it, or delete it in the calendar yourself.

Dates, Copying & Overdue Items

  • Use the ‹ / › arrows or the date picker to move between days, and the Today button to jump back.
  • Move to tomorrow: hover an item and click the →| arrow to push it to the next day in one click. Click it again on the new day to keep pushing it forward.
  • Move to a date: click the calendar icon and pick any day. The item leaves the current day and lands on the one you chose, keeping its time, project tag and text.
  • Copy to a date: click the duplicate icon to place a copy on another day while leaving the original where it is—handy for anything recurring.
  • Anything left unfinished on a past date is collected into a red Overdue panel at the top, with all of its controls permanently on show. Click → Today to carry an item forward.
  • If the next day already has unfinished items, a small Next Day line appears at the bottom—click it to jump there. It is always relative to the day you are looking at, and stays hidden when that day is empty.

Project Tags

  • Optionally tag an item to a project using the dropdown next to the add box.
  • Every item also carries its own tag dropdown, revealed when you hover the row, so you can change or remove the project at any time—including on items that were created without one. Once set, the project shows as a small colored badge on the right.
  • When an item is tagged, an open icon appears on hover next to the tag to jump straight to that project.
  • Tagging is entirely optional—leave it on "No project" for general items.

To Do items are saved with everything else—they are included in your LocalStorage, Live Auto-Save file, and JSON backups automatically.
